VIBE — clickable prototype

The Android app's flow and design system in one file, so every screen can be judged before the APK is built. Like the app it starts empty: no groups, ideas, plans or memories are pre-loaded; the demo account is all you begin with.

  1. Get started → sign in. The bottom bar appears once you are signed in.
  2. Home is empty → Create group (name + icon) for Friday Night Crew, Girls Trip, Game Squad — as many as you like. You own them and get an invite code to share.
  3. Add ideas, then Start decision. Vote NO/YES on every idea; results appear only when the round closes.
  4. Join with a code with any code that is not yours (e.g. PARTY7) and you land in a friend's group as a member: their owner starts the round, you vote, the other members vote, and an alert arrives when there is a winner.
  5. Quick Start: Can't Decide?, Surprise Me (accept or skip) and My Activities — all three work once a group exists.
  6. Top-right ✈️ flips airplane mode: changes queue up, the badge counts them, and reconnecting syncs — or asks you to settle a conflict.
  7. Settings: notification and privacy toggles, theme, language (English, isiZulu, Sesotho — labels and alerts), password, linked accounts.

The real client is Kotlin/Compose in app/; this file is a demo aid, not part of the build.
