VIBE — clickable prototype

The Android app's flow and design system reproduced in one file, so it can be clicked through before the APK is built. It starts empty, exactly like the app: no pre-loaded groups, ideas, plans or memories.

  1. Get started → sign in. The bottom bar only appears once you are signed in.
  2. Home is empty → Create group (name + icon). You become the owner and get an invite code to share; Join with a code shows what a wrong one does.
  3. On the group screen add a few ideas with the Add an idea button, then Start decision.
  4. Vote NO/YES on every idea. Results appear only once the round closes; vote YES on one idea and NO on the rest to crown a winner, with confetti, Plan it and Add to memories.
  5. The bottom bar is there while you browse (Home, a group, the Vibe List, Memories, the profile, the inbox) and steps aside during focused flows — creating a group, voting, planning, settings — where a back arrow takes over.
  6. Top-right ✈️ flips airplane mode — add an idea while offline and watch the change count drain when you reconnect.
  7. Surprise Me, the filter pills, Settings → Language (English, isiZulu, Sesotho) and the theme switch are live. Try Join with code with a wrong code to see the error message.

The real client is Kotlin/Compose in app/; this file is a demo aid, not part of the build.
