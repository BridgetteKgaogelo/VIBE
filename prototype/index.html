VIBE — clickable prototype

This is the Android app's flow and design system reproduced in one HTML file so it can be clicked through before the APK is built: same palette, same screens, same decision rules (`domain/DecisionEngine.kt`).

  1. Get started → sign in (demo member Lerato).
  2. Open Friday Night Crew → Decide For Us.
  3. Vote NO/YES on each idea. The other members "vote" after you, the round closes when everybody has, and results are revealed only then.
  4. Winner screen → Plan it → Mark as done with a rating and caption.
  5. Top-right ✈️ flips airplane mode: add an idea or vote while offline and watch "1 change waiting to sync" drain when you come back.
  6. Surprise Me, the filter pills, Settings → Language (English, isiZulu, Sesotho) and the theme switch are all live.

The real client is Kotlin/Compose in app/; this file is a demo aid, not part of the build.
